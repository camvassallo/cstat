# camalytics.org crawl policy.
#
# Two layers, kept in sync BY HAND — this file is the published policy, and
# Cloudflare AI Crawl Control (Security → AI Crawl Control → Crawlers, on BOTH
# the camalytics.org and campom.org zones) is the enforcement. A crawler that
# honours robots.txt never sends the request; one that does not is refused at
# the edge. Neither layer prepends anything to this file: an earlier version
# claimed Cloudflare's managed robots.txt was prepended here, and it was not
# (#343) — so a directive that is not written below is not published anywhere.
#
# Search crawlers (Googlebot, Applebot, Bingbot, …) are welcome on the SPA
# pages — /predict, /players/*, /teams/*, /coaches/* etc. — but NOT on the JSON
# API. /api/* routes aren't pages (no indexable content) and are the heaviest
# endpoints to serve (/api/predict runs model inference; /api/lineups and the
# per-player /pbp + /on-off routes are expensive queries), so there's no SEO
# value in crawling them and real cost in letting bots hammer them. The search
# engines honour this during rendering too — zero /api/ calls from any of them
# in the edge log — which is why the pages they index are the served HTML
# shell and its injected <head>, not the rendered app (#342).

User-agent: *
Disallow: /api/

# AI-TRAINING crawlers: no access at all. They fetch pages to train on or to
# index for their own products, and none of them sends a visitor. The one that
# executes JavaScript (meta-externalagent) rendered the app in headless Chrome,
# fetched /api/* like a browser in spite of the disallow above, and at ~10
# requests/s drove Postgres into statement_timeout (#338) — 85% of all origin
# traffic and 99.9% of crawler traffic on the day it was measured. This group
# is the same set blocked in AI Crawl Control; change both together.
#
# Deliberately NOT listed, because they are user-initiated or produce
# citations: facebookexternalhit and Meta-ExternalFetcher (link previews / OG
# cards), ChatGPT-User, Claude-User, Perplexity-User (someone pasted a link
# and asked about it), and the AI-search fetchers OAI-SearchBot, PerplexityBot,
# Claude-SearchBot, Applebot (they link the page back, like a search engine).

User-agent: meta-externalagent
User-agent: GPTBot
User-agent: ClaudeBot
User-agent: CCBot
User-agent: Google-Extended
User-agent: Bytespider
User-agent: Amazonbot
User-agent: Applebot-Extended
User-agent: PetalBot
Disallow: /
